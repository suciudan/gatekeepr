# Gatekeepr Documentation

This documentation is built using [Retype](https://retype.com). 

The source Markdown is included in this repository. The generated `.retype` output is intentionally not tracked.

Follow the [Getting Started](https://retype.com/guides/getting-started/) guide to install a current Retype CLI locally, then run:

```sh
yarn workspace docs dev
yarn workspace docs build
```
