# Welcome

Gatekeepr protects your platform from abuse by validating user signals before they take action. It checks email, domain, 
IP, and user agent against multiple criteria, including disposable addresses, domain age, disposable MX
infrastructure, blocklists, Tor usage, and automation.

Our documentation covers everything you need to know about:

- Authorizing your requests
- Sending your first request
- Description for the validation layers
